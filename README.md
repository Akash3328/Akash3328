# 🧩 How I Build

I approach DevOps as an engineering lifecycle rather than a collection of tools.

```text
                    ┌─────────────────────┐
                    │       SOURCE        │
                    │   Git / GitHub      │
                    └──────────┬──────────┘
                               ↓
                    ┌─────────────────────┐
                    │    CI / QUALITY     │
                    │ Tests · SonarQube   │
                    └──────────┬──────────┘
                               ↓
                    ┌─────────────────────┐
                    │      SECURITY       │
                    │ Trivy · Checkov     │
                    │ Gitleaks · SBOM     │
                    └──────────┬──────────┘
                               ↓
                    ┌─────────────────────┐
                    │     CONTAINER       │
                    │ Docker · Registry   │
                    └──────────┬──────────┘
                               ↓
                    ┌─────────────────────┐
                    │   INFRASTRUCTURE    │
                    │ Terraform · AWS     │
                    └──────────┬──────────┘
                               ↓
                    ┌─────────────────────┐
                    │     DEPLOYMENT      │
                    │ Kubernetes · ArgoCD │
                    └──────────┬──────────┘
                               ↓
                    ┌─────────────────────┐
                    │    OBSERVABILITY    │
                    │ Prometheus · Grafana│
                    │ Loki · OpenTelemetry│
                    └──────────┬──────────┘
                               │
                               └──────→ Improve
```

> **Automate what is repeatable.
> Secure what is exposed.
> Observe what is running.
> Improve what is measurable.**
